# 🏠 HomeGenie – On-Demand Home Services Platform

HomeGenie is a centralized web platform built to simplify **home service booking** and **supplier management**.  
It was developed as a **UCSC 2nd-year group project** using a **custom PHP MVC framework, MySQL, HTML5, CSS, and JavaScript**.  

## ✨ Features
- 👥 Role-based registration (customers, service providers, suppliers, admins)  
- 📅 Service appointment booking & tracking  
- 📦 Supplier item listings and inventory management  
- 🔐 Session-based authentication & secure access control  
- 🎨 Clean and modular MVC architecture with user-friendly UI
